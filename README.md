# Portfolio

Astro portfolio for Aditya Bhargava with a restrained monochrome visual system, subtle blue-grey accents, and a modular multi-page structure.

## Stack

- Astro
- MDX-ready content collections
- Custom CSS design system
- GitHub Pages via GitHub Actions

## Routes

- `/` home
- `/about/`
- `/projects/`
- `/blog/`
- `/photography/`
- `/contact/`

## Local Development

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

## GitHub Pages

The site is configured for the capital-`P` repository path:

- Live site: `https://aditya-200118.github.io/Portfolio/`
- GitHub profile: `https://github.com/Aditya-200118`

Make sure the repository Pages source is set to `GitHub Actions` so `.github/workflows/deploy.yml` is used.
